# 야화기방 프롬프트 조립기 🌙

조선시대 기방 컨셉 AI 이미지 서비스 **야화기방**의 캐릭터 이미지 프롬프트를 조립하는 도구입니다.
그림체·캐릭터·의상·헤어·체형·포즈·배경·비율을 슬롯으로 조합하면, 최종 프롬프트가 자동으로 합쳐집니다.

## ✨ 기능

- **그림체 고정** — 한국 BL 웹툰 반실사 화풍을 module A로 고정 (수정·저장·수정 로그 지원)
- **슬롯 조합** — 캐릭터 얼굴 / 헤어(6종) / 체형(4종) / 의상(10종) / 액세서리 / 포즈 / 배경 / 구도 / 비율을 자유 조합
- **캐릭터 관리** — 캐릭터 추가·수정·삭제, 브라우저에 저장, 수정 로그
- **중복 자동 제거** — 슬롯 간 겹치는 문구를 자동으로 걸러냄
- **정면·구도 최적화** — 구도·포즈를 프롬프트 앞에 배치, 정면 서술로 옆모습 방지
- **네거티브 프롬프트** — 목 길이·옆모습 방지용 네거티브 자동 제공
- **통합본 출력** — 프롬프트 + 네거티브를 `Negative prompt:` 형식으로 한 번에 (네거티브 칸 없는 툴용)

## 🚀 사용법

### 온라인으로 바로 쓰기 (GitHub Pages)
1. 이 저장소를 fork 또는 clone
2. Settings → Pages → Source를 `main` 브랜치로 설정
3. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 열림

### 로컬에서 쓰기
`index.html` 파일을 브라우저로 열면 바로 작동합니다. (설치 불필요)

### 조립 순서
1. **① 그림체** — 그대로 두거나 원하면 수정 후 저장
2. **② 캐릭터** — 캐릭터 선택 또는 새로 만들기
3. **②-2 헤어 / ②-3 체형** — 상황에 맞게 선택
4. **③ 의상 / 액세서리** — 원하는 조합 선택
5. **④ 포즈·배경·구도·비율** — 선택
6. **⑤ 최종 프롬프트** — 복사해서 이미지 생성 툴에 붙여넣기
   - **프롬프트 복사** → 프롬프트 칸
   - **네거티브 복사** → 네거티브 칸
   - **통합본 복사** → 네거티브 칸이 없는 툴(예: Flux 일부 UI)이면 이것만 붙여넣기

## 🎨 지원 툴

SeaArt, Stable Diffusion WebUI, ComfyUI 등 프롬프트 기반 이미지 생성 툴 대부분에서 사용 가능합니다.
- **SDXL / Pony 계열** — 프롬프트 + 네거티브 따로 사용
- **Flux 계열** — 네거티브를 잘 안 먹으므로, 프롬프트 앞쪽의 자연어 정면 서술이 중요. 통합본 사용 권장

## 💾 데이터 저장

캐릭터·그림체 수정 내용은 **브라우저 localStorage**에 저장됩니다.
- 같은 브라우저에서는 창을 닫아도 유지됩니다.
- 다른 사람과 공유하려면 이 저장소를 fork해서 각자 쓰면 됩니다. (저장은 각자 브라우저에 독립적으로 남음)
